# План развития учебного проекта

- [x] PostgreSQL для каждого сервиса; Redis cache-aside; инфраструктура Compose.
- [x] Единый auth-сервис, безопасное хранение паролей и JWT.
- [x] gRPC-проверка клиента перед бронированием.
- [x] Saga оформления договора с компенсацией; RabbitMQ; transactional outbox/inbox.
- [x] Unit- и интеграционные тесты, проверки контейнерного сценария.
- [x] GitLab CI и обновлённая документация.

Изменения сохраняются небольшими тематическими коммитами в локальный Git.
Публикация в удалённый репозиторий не выполняется автоматически.
