# План развития учебного проекта

- [ ] PostgreSQL для каждого сервиса; Redis cache-aside; инфраструктура Compose.
- [ ] Единый auth-сервис, безопасное хранение паролей и JWT.
- [ ] gRPC-проверка клиента перед бронированием.
- [ ] Saga оформления договора с компенсацией; RabbitMQ; transactional outbox/inbox.
- [ ] Unit- и интеграционные тесты, проверки контейнерного сценария.
- [ ] GitLab CI и обновлённая документация.

Изменения сохраняются небольшими тематическими коммитами в локальный Git.
Публикация в удалённый репозиторий не выполняется автоматически.
